# jrSiCKLSNMF
This package contains code to run joint graph-regularized single-cell Kullback-Leibler Non-negative Matrix Factorization. The code here is currently being migrated; please use the CRAN version of jrSiCKLSNMF.

To install the CRAN version:

```{r CRAN}
install.packages("jrSiCKLSNMF")
```

If you still would like to install the code here for some reason, please use: 

```{r package}
install.packages("devtools")
devtools::install_github("ellisdoro/jrSiCKLSNMF")
```
